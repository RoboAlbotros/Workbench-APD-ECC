Access control

Users

Admin-Full and Admin-Global users can open this console and restore archived applicants. Admin-Global sign-in requires a named Admin-Global user. Admin-Staff users sign in as Admin-Staff, can use Full Admin, and can review archived records, but cannot restore applicants or open this console. Admin-Full, Admin-Global, and Admin-Staff can delete from Archived Records. Read Only users sign in as Read Only. Shared Read Only and Admin-Full access codes still work. Prototype codes stay in this browser only.
