# Architecture Decision Records (ADRs)

Material architecture decisions for this project are recorded here per Rule 10
(`.governance/rules/10-architecture.md`).

## Naming

`ADR-NNNN-short-title.md` (example: `ADR-0001-sql-localhost-persistence.md`)

## Required sections

Each ADR MUST include:

- Status
- Context
- Decision
- Consequences
- Owner
- Date

## Notes

- Creating this folder does not satisfy G-ARCH.
- Scaffolding such as `docs/architecture/sso-entra-id.md` is not an ADR until
  rewritten and accepted in this directory with the fields above.
