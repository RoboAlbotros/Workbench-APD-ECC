# CJIS Applicant Tracker — leadership video package

This folder is the source packet for an approximately 60-second video for City leadership. Zip this folder as-is. It contains no real applicant records, no staff names from the tracker, and no access codes.

Start here, then read the pieces in order:

1. `01-overview.md` — what the application is, in plain language.
2. `02-narration-script.md` — the voiceover.
3. `03-shot-list.md` — the picture, on-screen text, and transitions for each line.
4. `04-confirm-before-filming.md` — facts that are still open, and screens that must stay off camera.
5. `stills/` — reference frames from a sanitized local copy, loaded only with fictitious people.
6. `sample-data/` — those same fictitious people, if a later session needs to recreate the motion.

The stills were captured on Thursday, November 12, 2026, at about 4:33 PM America/Denver. The development footer was hidden for these frames. It is still part of the live page and should stay cropped in the edit.

## What was reviewed

The script follows the approved product definition (October 8, 2026) and the application as it stands in `CJISTracker/` now: the page layout, the applicant lists, the status lookup, the record window, the counts, and the change log. Later notes about an older column layout were not used where the current screen differs.

## What this video can say

The tracker gives City staff one record for each applicant’s clearance: the information received, fingerprints, security awareness training, certification dates, and a follow-up inquiry dated five years after completion. Staff can look up a status or open the full record. The top of the screen counts active applicants, inactive applicants, and inquiries that are due. Updates are kept in a change log on the record.

## What this video cannot say

No result in the project record measures time saved, errors reduced, money saved, or how many spreadsheets have been retired. The footer identifies this build as a development version. City single sign-on is the recorded direction for a later production sign-in and is not the sign-in on this screen. The tracker does not run a background check and does not connect to state or federal criminal justice systems.

## Safe picture

Use the stills in this folder, or a separate copy of the page loaded only with `sample-data/fictitious-test-applicants.js`. The application’s own built-in sample includes real staff records. Keep that sample off camera. Keep Settings closed. The Settings button is visible on the real screen; leave it unclicked.
