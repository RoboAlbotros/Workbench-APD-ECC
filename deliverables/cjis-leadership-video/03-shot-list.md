## How to treat each frame

**01 — Full list.** Six fictitious applicants, sorted by name: Brooks, Chen, Nguyen, Ortiz, Patel, Rivera. Status badges are the story. Chen’s row is shaded because security awareness training expired on 02/01/2026. Brooks and Ortiz are inactive and are not shaded. Patel is the one-time visit. Nguyen is the person behind the “1 Query Due” count; that date is not a column on this list, so the count carries that point. Rivera is the active full-clearance example used in the record window.

**02 — Inactive only.** Optional. The Activity filter is set to InActive, so three rows remain, and the top counts stay at 6, 3, and 3. Use it as a glimpse. Skip it if the shade on Chen’s row would be heard as “inactive,” because the other two inactive rows are not shaded.

**03 — Read Only list.** Five rows. Patel is absent: Read Only does not list one-time visits, while the One Time Visit count still shows 1. This frame also shows a driver’s license column beside a pill that says “Sensitive fields hidden.” That combination is easy to misread. Prefer frame 04 for the spoken line about looking something up, and keep frame 03 out of the cut unless that column is covered.

**04 — Status lookup.** The short window for Rivera. It shows the clearance path and the calculated inquiry date, and it omits the license number. The dimmed list behind it still shows demonstration license numbers. Cover that column in the background, or keep the window large enough that the column is not readable.

**05 — The record.** View mode. The window title says “Applicant Details - Read Only” because the record is not being edited. An administrator opened it. The voiceover should call it the applicant record, not a separate product. The license field shows `NM/DEMO1001`. Phone and email are blank. Source says VIDEO SAMPLE. The yellow outline on the last name is the cursor; it does not need a mention. Physical and Non VPN appear grayed out. Leave them unspoken.

**06 — Change log.** Same record after one demonstration edit. The note reads “Sample note added for the demonstration.” The log names the field, Notes, and the person, Sample Coordinator. It does not show an old value and a new value. A banner above the search box may read “Applicant record saved.” That banner can be cropped.

## On-screen text

Keep titles short. Place them in the lower third or in the open area under the list, clear of the counts and the Active badge. Use one line at a time. “Demonstration records” belongs on the first application shot, then it can leave.

Match the product name on the page. An internal address uses the words “clearance tracker.” Leave the address off camera, and leave that second name off the title card unless leadership chooses it. See the confirm list.

## Picture that stays out

- The sign-in form and any access code
- Settings, including users, database fields, authenticator setup, and single sign-on fields
- The footer and its version line
- New Applicant, Archived Records, and the search box as teaching moments
- Import, export, and document upload
- Any screen loaded with the application’s built-in sample

## Pace

If the minute is tight, drop frame 02 and the second hold on frame 05. Keep the title, the full list, Rivera’s calculated date, the short lookup, the counts, the change log, and the end card. Those six pictures carry the story.
